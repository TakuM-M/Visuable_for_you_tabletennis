# コンポーネントの名前
- 中規模のシステム開発
- このプロトタイプを作成したらバックエンドの設計に進む

## 概要
- 動画を受け取り骨格データからプレーシーンを判定し，切り抜きされた動画を返す．

## テストケース
- 正常系
    - 動画をアップロードし，プレーシーンが正しく切り抜かれることを確認する．
- 異常系
    - 不正な動画フォーマットをアップロードした場合，エラーメッセージが表示されることを確認する．
    - 卓球台が検出されない場合に，適切なエラーメッセージが表示されることを確認する．


## レビュー指摘事項
- [] 卓球台の検出ロジックについて，動画の途中で卓球台の位置が変わる場合を想定していない
- [] 判別モデルについての学習データについて，データ数が非常に少ない
- [] 使用する分類モデルについて，LSTMを使用予定だが他のモデルについての検討をしていない
- [] エラーの場合についての挙動が不明確
- [] 処理する際のコンフィグの最適設定が不明確
