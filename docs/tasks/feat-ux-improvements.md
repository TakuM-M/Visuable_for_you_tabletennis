# feat: UX改善

**Status: In Progress**

重要度: 低〜中

## 背景・目的

機能面は揃ってきたが、進捗が見えづらい・動画閲覧が不便・モバイル UI が崩れる等の細かい UX 課題が積まれている。ユーザーの離脱を防ぐためまとめて改善する。

## 受け入れ条件

- [ ] 処理進捗が「ステータス文字列」だけでなく段階（アップロード / 検出中 / クリップ結合 / 完了）が分かる UI になっている
- [ ] 動画プレイヤーでクリップ単位のシーク（タイムライン or チャプター）ができる
- [ ] スマホ・タブレットで主要画面（ログイン / アップロード / 結果表示）が崩れない
- [ ] エラー時のメッセージがユーザーに分かる文言になっている

## 関連ファイル

- `frontend/src/pages/`
- `frontend/src/components/`
- `frontend/src/lib/chunkedUpload.ts`
- `backend/app/routers/jobs.py`（進捗の詳細化が必要なら）

## 設計メモ

- 進捗詳細化は backend 側で `jobs.progress_stage` 等を追加すべきか要検討
- プレイヤーは `video.js` / `Plyr` 等のライブラリ採用も視野
