# fix: 卓球台検出ロジックの堅牢化

**Status: In Progress**

重要度: 中

## 背景・目的

ML パイプラインの卓球台検出ロジックは、最初のフレームで検出した卓球台位置を固定で使う前提になっており、(1) 最初に誤検出した場合に全フレームでズレ続ける、(2) 試合途中でカメラ画角が動いた場合に追従できない、という問題がある。検出の頑健性を上げ、誤検出・画角変化に対応する。

## 受け入れ条件

- [ ] 一定周期 or 検出スコア低下を検知して卓球台再検出が走る
- [ ] 複数フレームの検出結果から外れ値を除いた安定推定ができる
- [ ] カメラ画角変化を検知するヒューリスティック（or モデル）が動作する
- [ ] 既存テスト用動画でリグレッションがないことを確認
- [ ] 新しい挙動が `docs/` か README に明文化されている

## 関連ファイル

- `ml/src/pipelines/inference_pipeline.py`
- `ml/src/` 配下の卓球台検出関連モジュール
- `ml/runpod_handler.py`（呼び出し側）
- `ml/mock_app.py`（必要ならダミー応答整合）

## 設計メモ

- 「画角変化」の検知は、検出した卓球台の bbox 中心や面積の急変で見るのが一案
- パフォーマンス劣化（毎フレーム再検出 → コスト増）とのトレードオフを意識
