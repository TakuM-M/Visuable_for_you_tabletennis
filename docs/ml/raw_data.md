# データ獲得
## yt-dlpの使い方
### 基本コマンド
```bash
yt-dlp "動画のURL"
```
**品質指定**
```bash
# 最高画質で取得
yt-dlp -f "best" "URL"
# 720pで取得
yt-dlp -f "best[height<=720]" "URL"
# 1080pで取得
yt-dlp -f "best[height<=1080]" "URL"
```
**形式指定**
```bash
# MP4形式で保存
yt-dlp -f "bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]" "URL"
```
**保存先とファイル名**
```bash
# 保存先ディレクトリ指定
yt-dlp -o "~/Downloads/%(title)s.%(ext)s" "URL"
# カスタムファイル名
yt-dlp -o "tabletennis_video.mp4" "URL"
```
### 卓球動画収集向けの推奨コマンド
```bash
# 1080p MP4形式で、タイトル付きで保存
yt-dlp -f "best[height<=1080][ext=mp4]" \
       -o "raw_02_training/%(title)s_%(id)s.%(ext)s" \
       "動画URL"
```

## 現在のモデル仕様
- **入力**: 17キーポイント × 2座標 = 34次元
- **キーポイント**: COCO形式（nose, eyes, ears, shoulders, elbows, wrists, hips, knees, ankles）
- **正規化**: 腰中心を原点、腰幅でスケーリング
- **シーケンス長**: 30フレーム
## データ拡張
- **左右反転**: プレイヤーの利き手の違いをシミュレート
- **回転（±15度）**: 姿勢の微妙なバリエーション
- **スケーリング（0.9-1.1倍）**: 体格差のシミュレート
- **ガウシアンノイズ（std=0.02）**: ポーズ推定の誤差をシミュレート
- **関節ドロップアウト**: オクルージョンのシミュレート
- **推奨設定:**
```python
augmentation_factor = 5  # 5倍に拡張
```

## データのジャンル
### プレースタイル
- ドライブマン
- カットマン
- ぺンホルダー
- 異質ラバー使用者
### 人間情報の違い
- 身長差が大きいペア（±20cm以上）
- 体格差が大きいペア（痩せ型 vs 筋肉質）
- 異なる年齢層（子供・学生・社会人・高齢者）
### ラリーの違い
- 高速ラリー（1秒あたり3打以上）
- 通常速度ラリー
- 緩急のあるラリー
### 技術の違い
- 低い姿勢（レシーブ）
- 高い姿勢（スマッシュ）
- 横向き姿勢（回り込み）
- 不安定な姿勢（体勢を崩したプレー）
- サーブ動作のバリエーション
### 撮影画角の違い
- エンドライン側（選手の後ろ）
- サイドライン側（横から）
- 斜め上から
- カメラ高さのバリエーション
