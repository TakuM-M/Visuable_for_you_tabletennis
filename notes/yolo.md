# YOLO

## トラッキング機能
YOLOモデルにはトラッキング機能が組み込まれている．BoT-SORT または ByteTrack アルゴリズムを使用している．
- 基本的な流れ:
1. フレームt: 人物を検出 → ID付与（例: ID=1, ID=2）
2. フレームt+1: 新しく検出
3. マッチング処理:
   - 前フレームの位置とバウンディングボックス
   - 現フレームの位置とバウンディングボックス
   - IoU（重なり具合）と動きベクトルで同一人物を判定
4. ID継続: 同一人物と判定されたらIDを継承

- IDが変わる場合:
    - 一時的に見えなくなる（遮蔽）→ 数フレーム後に再検出 → 新しいID
    - 急激な移動 → マッチング失敗 → 新しいID
    - 画面外に出る → 消失 → 再登場時は新しいID
